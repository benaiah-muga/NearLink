# Project instructions

- Do not use em dashes anywhere in the project. This applies to source code, documentation, commit messages, comments, and user-facing copy.
- Use subagents for implementation work and separate subagents for independent review when the task has suitable work boundaries.
- Commit each completed milestone with a clear conventional commit message.
- Never claim end-to-end encryption or emergency-grade reliability unless those capabilities have been implemented and independently reviewed.
- Keep browser code independent of hub internals and keep protocol behavior transport-independent.
- Do not add external cloud dependencies to core communication flows.
